TTF
===

This project hosts interesting TTF files useable (for example) as a polyfill in your js13kgames entries

Emoji Color Fonts
-----------------

1) Noto Color Emoji (N.ttf) - Unicode 17.0

```
@font-face { font-family: emoji; src: url(//xem.github.io/ttf/N.ttf) }
```
